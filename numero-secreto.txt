O QUE É?

Os comandos Git são instruções executadas no terminal para controlar o
versionamento de um projeto. Eles permitem registrar alterações,
acompanhar o histórico e sincronizar projetos com o GitHub.

PARA QUE SERVE?

- Controlar versões de um projeto.
- Registrar alterações.
- Trabalhar em equipe.
- Recuperar versões anteriores.
- Enviar e receber alterações do GitHub.

--------------------------------------------------
1. Configuração inicial
--------------------------------------------------

Define as informações do usuário.

git config --global user.name "Seu Nome"
git config --global user.email "seuemail@email.com"

Verificar configurações:

git config --list

--------------------------------------------------
2. Criar um repositório
--------------------------------------------------

Inicializa um repositório Git.

git init

--------------------------------------------------
3. Clonar um repositório
--------------------------------------------------

Cria uma cópia de um repositório remoto.

git clone URL_DO_REPOSITORIO

Exemplo:

git clone https://github.com/usuario/projeto.git

--------------------------------------------------
4. Verificar o estado
--------------------------------------------------

Mostra os arquivos modificados.

git status

--------------------------------------------------
5. Adicionar arquivos
--------------------------------------------------

Adicionar um arquivo:

git add arquivo.txt

Adicionar todos os arquivos:

git add .

--------------------------------------------------
6. Criar um commit
--------------------------------------------------

Salva as alterações no histórico.

git commit -m "Mensagem do commit"

Exemplo:

git commit -m "Adiciona tela de login"

--------------------------------------------------
7. Histórico
--------------------------------------------------

Mostrar todos os commits:

git log

Versão resumida:

git log --oneline

--------------------------------------------------
8. Diferenças
--------------------------------------------------

Visualizar alterações antes do commit.

git diff

--------------------------------------------------
9. Repositório remoto
--------------------------------------------------

Adicionar um remoto:

git remote add origin URL_DO_REPOSITORIO

Verificar:

git remote -v

--------------------------------------------------
10. Enviar alterações
--------------------------------------------------

Primeiro envio:

git push -u origin main

Próximos envios:

git push

--------------------------------------------------
11. Baixar alterações
--------------------------------------------------

Atualizar o projeto local.

git pull

Baixar sem atualizar:

git fetch

--------------------------------------------------
12. Branches
--------------------------------------------------

Criar uma branch:

git branch nome-da-branch

Listar branches:

git branch

Trocar de branch:

git switch nome-da-branch

ou

git checkout nome-da-branch

Criar e trocar:

git switch -c nome-da-branch

ou

git checkout -b nome-da-branch

Mesclar:

git merge nome-da-branch

Excluir:

git branch -d nome-da-branch

--------------------------------------------------
13. Restaurar alterações
--------------------------------------------------

Descartar alterações:

git restore arquivo.txt

Remover da área de staging:

git restore --staged arquivo.txt

--------------------------------------------------
14. Ver versão do Git
--------------------------------------------------

git --version

==================================================
RESUMO
==================================================

Fluxo básico:

Editar arquivos
      ↓
git status
      ↓
git add .
      ↓
git commit -m "mensagem"
      ↓
git push

--------------------------------------------------

Comandos mais usados:

git init        -> Criar repositório
git clone       -> Clonar repositório
git status      -> Verificar alterações
git add         -> Adicionar ao staging
git commit      -> Registrar alterações
git log         -> Ver histórico
git diff        -> Comparar alterações
git push        -> Enviar ao GitHub
git pull        -> Atualizar projeto
git fetch       -> Buscar alterações
git branch      -> Gerenciar branches
git switch      -> Trocar de branch
git merge       -> Mesclar branches
git remote      -> Gerenciar remotos
git restore     -> Restaurar alterações
